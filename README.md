# XTO.STICKER · Arte Adhesivo

Tienda web de stickers en un solo archivo (`index.html`), sin dependencias ni servidor.

## Secciones

- **Catálogo**: más de 150 stickers filtrables por categoría (Humor, Caricaturas, Fútbol, Rock y Metal, Anime y Pokémon, etc.).
- **Mi hoja**: plantilla A4 donde se arrastran y redimensionan los stickers elegidos.
- **Vinilos y precios**: precio por sticker según material y tamaño, con descuentos por cantidad.
- **Mi foto**: el cliente sube su propia imagen para convertirla en sticker.
- **Mi pedido**: resumen del carrito, datos del cliente y envío del pedido.

Incluye tema claro y oscuro. Las imágenes van incrustadas en el HTML.

## Uso

Abre `index.html` en el navegador o publícalo en cualquier hosting estático (por ejemplo, GitHub Pages).
